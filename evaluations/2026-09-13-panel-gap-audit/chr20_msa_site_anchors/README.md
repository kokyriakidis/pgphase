# MSA anchor experiment: not accepted

The six-case screen added the 12.74 Mb join with zero discordant assessed reads. The full 114-case panel yielded 85 joined, 25 split and four unphased-endpoint targets, versus the accepted 86/24/4 baseline.

Three joins were added (12.74, 53.9 and 61.7 Mb), but four existing joins were lost (7.0, 20.5, 21.1 and 38.2 Mb). No read-error increases or original-block majority reversals were detected. This is not accepted because contiguity regressed elsewhere.

The trial reassesses provisional homozygous MSA indels using partial-read observations and a reference hypothesis, fixes ASCII/nt4 homopolymer insertion classification, preserves the original gap eligibility interval across tiers, and permits independently clean-supported MSA sites to validate neighboring repeats. Newly validated sites cannot validate one another. The component bridge remains clean-SNP-only.

The six-case success was insufficient to establish general improvement. The production source excludes this experiment; its patch is archived alongside this report. Competitors and read truth supply evaluation only, never phasing evidence.
