# Phase-scoped k-means: isolated diagnostic trial

This trial applies per-phase-set iterative read scoring and allele updates, then scores output HP within its reported PS. The new unit fixture fails against the original core and passes with the change.

The full 114-case run has 89 joined targets, 23 split and two endpoint-unphased. Both 1.9 Mb endpoint cases join: assessed read errors fall 30 to 3 and read switch/flips 10 to 3. Direct WhatsHap variant-truth comparison in the 1.9 Mb window assesses 203 rather than 171 variants and reduces blockwise hamming 5 to 1.

NOT accepted alone: the 3.95 Mb join reverses the original right block (119 assessed reads and 11 of 35 assessed variants). The 4.85 Mb target loses its previous join after a partial extension excludes evidence from the later homopolymer tier. At the ambiguous 26.6 Mb case, one individual read error and one switch/flip are added. These findings require additional evidence/eligibility fixes before accepting the core change.

variant_truth_comparison.tsv is generated by compare_panel_variant_truth.py using WhatsHap compare on exact local truth windows. Local overlapping-window counts are not whole-chromosome NGC50/hamming estimates. Changes in phased coverage change the comparison denominator.
