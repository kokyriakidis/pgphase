# Diagnostic experiment

Adds an override for an independently pure clean-SNP anchor, supported on both alleles by primary MAPQ30/Q30 BAM observations. Unit tests reject low-quality or conflicting observations. Eleven-case results remain unchanged from scoped_vetted_indels; the additional repeat-edge margin still prevents the 7.0 Mb join. Not accepted as a final implementation.

Results are overlapping local windows. Competitors and truth are used only for evaluation. See manifest.json, baseline_comparison.tsv and summary.json.
