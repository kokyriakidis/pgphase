# Remaining-gap diagnostic trial

Six-case cumulative experimental trial adding an exact Q30 BAM SNP alternative to the two-clean-SNP bridge requirement. Correct joins at 18.2 and 54.9 Mb, no extra read errors in these cases; 46.7 Mb remains split. Includes unvalidated indel/read-scoring changes, so see confident_clean_bridge for an isolated implementation.

The comparison baseline is chr20_multi_final. These are overlapping local
windows; they do not establish whole-chromosome accuracy or NGC50.
